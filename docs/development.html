Workspace ownership and native prerequisites

The root workspace builds its six checked-out support/exchange crates, rather than silently exercising their published registry copies. The incomplete Huobi crate remains outside the supported workspace because its original sibling nash-ws dependency is unavailable. Nash protocol/client are the latest published 0.3.0 sources with their original licenses and documented local exchange type identity patches: protocol provenance, client provenance.

On macOS, install GNU GMP and expose its native library directory before building:

export LIBRARY_PATH="$(brew --prefix gmp)/lib${LIBRARY_PATH:+:$LIBRARY_PATH}"
cargo build --workspace --all-targets --locked
cargo test --workspace --no-fail-fast --locked

Coinbase product size limits removed by the exchange are optional fields, preserving the distinction between absent limits and zero. Public order-book subscriptions use level2_batch, accepting its actual level2_50 acknowledgement alias. Binance exchange metadata includes current side-specific percentage, notional, amendment and order-list filters as typed variants. Consult Coinbase channel/schema documentation and Binance filter documentation.

Authenticated account cases require the credentials declared in their existing fixtures. Their missing prerequisites are recorded separately from public-data failures in validation; they are not replaced with fabricated responses.
